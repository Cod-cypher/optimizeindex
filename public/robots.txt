# The wildcard group above already allows all of these. They are named anyway so
# the decision is visible and deliberate: a future edit that tightens the
# wildcard would otherwise silently remove this site from the assistants it is
# built to be cited by.
#
# Every group repeats `Disallow: /admin`. That repetition is required, not
# stylistic - a crawler obeys only the most specific group that matches its
# name, so a named group without it would grant that crawler access to the
# private admin app which the wildcard group denies.
#
# Note Google-Extended governs Gemini Apps grounding and Gemini model training,
# and per Google "does not impact a site's inclusion in Google Search nor is it
# used as a ranking signal in Google Search". Google's AI features need a page
# to be "indexed and eligible to be shown in Google Search with a snippet",
# which is Googlebot's job. Allowing or blocking Google-Extended therefore
# changes nothing in Search (both checked 2026-10-12:
# https://developers.google.com/search/docs/crawling-indexing/google-common-crawlers
# https://developers.google.com/search/docs/fundamentals/ai-optimization-guide).
